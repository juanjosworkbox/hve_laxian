# hve_laxian - In Gaming GPU LLM Hypervelocity Engineering Galaxian Clone 
- Learning work in progress.
- Creating a Galaxian Clone using HVE Core runing on a local 3090 GPU of 24 GB VRAM, using Llama.cpp, and unsloth quantization of Qwen3.6-35B-A3B-MTP-UD-Q3_K_XL.gguf open weights model, with Yarn extended --ctx-size 505000
